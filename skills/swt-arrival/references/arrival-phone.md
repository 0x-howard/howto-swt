# 美国电话卡：选卡与回国保号

整理自 Howard《J1 学生青年大学习》和《Tello 低成本保号教程》，套餐和价格核验于 2026 年 7–9 月，付款前以运营商页面为准。

美国手机号是雇主、SSA、银行和券商的验证入口。银行、SSA、券商等重要账户要绑定本人长期控制、能正常接打电话和收短信的美国号码，不要用 Google Voice、TextNow 等虚拟号码。

## 手机能装什么卡

1. 先查自己的手机是否支持 eSIM；
2. 在设置里找 EID 或“添加 eSIM”入口；
3. 到运营商网站输入 IMEI，确认能否激活。

| 手机 | 建议 |
|---|---|
| 美版 iPhone 14 及以后 | 没有实体卡槽，只能用 eSIM；落地激活时准备 Wi-Fi |
| 国行、港澳版 iPhone | 型号差异大，以“设置—蜂窝网络—添加 eSIM”为准 |
| Samsung、Google Pixel | 地区版本差异大，核验 eSIM、频段和 IMEI |
| 华为、小米、OPPO、vivo、一加 | 大陆版和国际版不同，重点查 EID、频段和兼容性 |

想以后常在海外发展的，港澳版 iPhone 最方便：既能用 eSIM，又能插实体卡。国内卡开漫游通常只有流量，适合落地过渡。

## 套餐怎么选

优先预付费：不查信用、不签合约，能按月停用或降档，最好有 App 能自己切换套餐。

| 品牌 | 参考价格 | 适合 |
|---|---|---|
| US Mobile | 低流量约 8 美元／月；无限约 22.50 美元／月 | 想测试或切换主网 |
| Tello | 2GB 约 10 美元／月；10GB 约 15 美元／月 | 按月用、回国低成本保号 |
| Mint Mobile | 新客前三个月常见 15 美元／月 | 确认 T-Mobile 信号好，能一次预付三个月 |
| Visible | 无限约 25 美元／月起 | Verizon 信号好、流量需求大 |
| Total Wireless | BYOD 无限常见约 25 美元／月 | 用 Verizon 网络 |
| AT&T Build-A-Plan | 1GB 约 15 美元／月；15GB 约 25 美元／月 | 想用 AT&T 直营 |
| Cricket | 10GB 约 30 美元／月；无限约 35 美元／月起 | 需要实体门店帮忙 |

“无限流量”不等于全程高速：Tello 一般 50G 高速，用完降速。多关注各家活动，例如 Tello 十周年时无限套餐 3 个月每月只要 10 美元。

## Tello 低成本保号

Tello 是回国保号的首选，低价档约 5 美元／月（约 35 元人民币）。

**推荐注册链接**：https://tello.com/account/register?_referral=P33V8D25

**前提**：

1. 首次激活或转号要在美国完成；
2. 手机已解锁，兼容 Tello 的 eSIM 或实体 SIM；
3. Tello 账户里保存了真实的美国 E911 地址；
4. 套餐持续有效，手机打开 Wi-Fi Calling。

**成功标准**：打开飞行模式只开 Wi-Fi，仍能呼入、呼出并收发普通短信。

**步骤**：

1. 用上面的推荐链接注册，进入 Build Your Own Plan。保号选“2GB 流量＋0 分钟”，税后约 6.15 美元／月；“0 流量＋300 分钟”税后约 8 美元，不划算。
2. 设置 E911：账户菜单 → My Settings → Wi-Fi Calling 下点 Add Emergency Address → 填真实美国地址保存，确认 Not configured 已被地址替代。
3. 打开 iPhone Wi-Fi Calling：设置 → App → 电话 → WLAN Calling；找不到时走 设置 → 蜂窝网络 → 选 Tello 号码 → Wi-Fi 通话。双卡手机先选 Tello 线路，再打开 WLAN Calling on This iPhone。
4. 出国前验收：开飞行模式，再手动开 Wi-Fi，等状态栏出现 Wi-Fi Calling，测试呼入、呼出、普通短信和常用平台验证码。

**离美前的多重准备**：在美国境内开好 Wi-Fi Calling 和 E911；套餐降到低价档并确认 AutoPay 在境外能扣款；保存 Account Number、Port-out PIN 和客服入口；银行、邮箱、券商另设验证器、备份代码和可信邮箱，不只依赖短信。

**长期保号只做四件事**：保持套餐 Active、支付卡不过期；每月测一次呼入和普通短信；换机、系统更新或重置网络后重新检查 Wi-Fi Calling；保存 Account Number 和 Port-out PIN。

**常见问题**：

- 开关打不开：先检查 My Settings 里 E911 地址是否保存成功。
- 家里 Wi-Fi 能用，酒店或学校不能用：公共网络可能阻断 Wi-Fi Calling，换网络再试。
- 普通短信正常，某家银行验证码不来：通常是对方风控或短码限制，联系该平台。
- My Tello App 能通过 Wi-Fi 拨出，但不能代替线路接电话和收短信。
- 彩信（MMS）不稳定，重要信息用普通短信。

人在海外遇到紧急情况，拨打当地报警号码，E911 只对应美国地址。
