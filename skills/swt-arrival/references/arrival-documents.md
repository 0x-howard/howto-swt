# 在美证件：驾照、州 ID、J1 转 F1

整理自 Howard《J1 学生青年大学习》，规则核验于 2026 年 7 月。不构成移民或法律意见；办理前让学生按下方官方入口再核对一次。

## J1 转 F1 继续留美读书

适合家里能拿出约 2 万美元、想继续留美读书的学生。签证是入境文件，身份是合法停留资格。

**出境申请 F1 签证**（有拒签风险）：取得 SEVP 认证学校录取和 I-20 → 按新的 F1 SEVIS ID 缴 350 美元 I-901 费（不能沿用 J1 收据）→ 与 Sponsor 完成 J1 项目 → 重新填 DS-160、缴 185 美元签证费并预约 → 准备 I-20、I-901 收据、录取、资金证明和 J1 项目时间线 → 获签后最早在 I-20 开学日前 30 天入境。

**美国境内转 F1 身份**：须合法入境、在 J1 有效期内递交、没有未授权工作或逾期、取得 Change of Status I-20 并重新缴 F1 I-901 费、证明全日制学习目的和资金、不受未履行或未豁免的 212(e) 两年回国要求限制（看签证页），按当期要求提交 Form I-539。

2026 年最新政策：无法在美国申请新的签证，必须回护照国重新申请。I-539 待审不代表已取得 F1，也没有 F1 工作权限。2026 年 9 月 15 日起，F1 停留期通常按 I-20 确定，最长不超过 4 年。

## 用 J1 身份申请美国驾照

两条红线：必须在自己实际居住的州申请，不能编地址跨州办证；拿到驾照不等于可以把 SWT 工作改成 Uber、送客或职业司机。

驾照的用处：合法驾驶、积累美国驾驶记录、办车险、买车、租车。

**常见材料**：护照、J-1 签证、I-94、DS-2019；SSN，或不具备 SSN 资格时 SSA 出具的证明；一到两份本州住址证明；雇主、学校或 Sponsor 证明；外国驾照及合规翻译件；DMV 申请表。

| 对比 | 新泽西 | 纽约 | 南卡 |
|---|---|---|---|
| 身份体系 | 6 Points of ID | ID-44 六分证明 | MV-94 国际客户清单 |
| SSN | SSN、ITIN 或无 SSN／ITIN 宣誓书 | Standard 可用 SSN 或 NSS-1／NSS-1A；REAL ID 通常需 SSN 或 SSA 信 | SSN 或 SSA 拒绝发号信 |
| 地址证明 | Standard 一份；REAL ID 两份 | Standard 一份；REAL ID 两份 | Standard 一份；REAL ID 两份且来自不同机构 |
| 中国驾照 | 原件＋认证翻译；视力和笔试必考，路考由 MVC 决定 | 不直接换证；笔试＋5 小时课程＋路考 | 不互认；笔试和路考都要考 |
| 等待 | 免路考则无需；否则按 GDL 规则 | 18 岁以下 Permit 等 6 个月 | 18 岁以上 Permit 等 30 天 |
| 政府费用 | Permit 10 美元；Standard 24 美元；REAL ID 35 美元 | 约 64.25–90 美元 | 最低约 17 美元 |
| 主要卡点 | 外国驾照核验及是否路考 | 课程和路考排期，通常 3–5 周 | 30 天等待期及指定网点 |

**一般流程**：确认申请路径（有中国驾照先查 Out-of-Country Transfer、Reciprocity、Road Test Waiver）→ 预审材料，姓名和地址完全一致 → 预约能处理国际客户的网点 → 身份、视力和理论核验（可能要 SAVE 二次验证，不等于拒绝）→ 取得 Permit，完成课程和等待期 → 准备路考车辆（Registration、Insurance、Inspection、陪同驾驶人）→ 通过后保存临时驾照，跟踪实体卡邮寄。

偏远地区的学生要算好时间，别项目结束了驾照还没办完。

## 申请州 ID

州 ID（State ID／Non-driver ID）是州政府签发的照片证件，不含驾驶资格。可以在银行和券商 KYC、酒店入住、领包裹、办手机卡、买酒年龄核验等场景代替护照。免费或费用很低时，也可以留作纪念。

| 类型 | Standard | REAL ID |
|---|---|---|
| 日常身份核验 | 可以 | 可以 |
| 单独用于美国国内航班 | 不可以 | 可以 |
| 南卡首次地址证明 | 通常一份 | 两份不同机构、地址一致的证明 |
| 有效期 | 由州法和身份文件决定 | 不超过获准停留期；无明确日期时通常最多一年 |

材料同驾照常见材料（不需要外国驾照）。南卡流程：选 Standard 或 REAL ID → 按 MV-94 准备材料 → 去指定国际客户网点 → SAVE 核验 → 拍照签名 → 领临时证明 → 等实体卡。
