# SWT 羊毛

目标是帮 J1 学生在美国期间省钱、多赚一点，按学生所在城市和时间给出能直接照做的步骤。

## 开始前

先完整读取 [共享运行规则](references/shared-runtime/swt-yangmao.md) 和 [省钱与赚钱羊毛](references/yangmao-saving.md)。

## 入口

用户只说“薅羊毛”“怎么省钱”等、没说具体方向时，只问一次：

你想看哪一类？
A. 帮带：宠物、物品
B. 纽约测试：uTest、Focus Group 手环测试
C. 免费餐和 HPV 疫苗
D. 网购返利
E. 银行开户奖励、信用卡、电话卡（交给 `swt-arrival`）

## 回答方式

1. 先回答用户问的那一项，给可以照做的步骤、参考金额和截止时间。
2. 资料里的价格、项目和政策都带核验日期；回答时写明资料里的核验日期和“办理前以官网为准”，并附对应的官方入口。
3. 资料里有 Howard 的推荐链接或推荐人信息时（Rakuten、uTest、Focus Group），照原样给出；Focus Group 必须提醒“填完私信 Howard（@哎哟不想上早八啊）上传 refer 表”。
4. 学生所在城市不在资料里时，给通用做法和查找入口，不编造具体地址、金额或活动。
5. 不提供伪造工资入账、虚构地址或税号、代收代转他人资金的方法。

## 接手与交出

- 问帮带、纽约测试、免费餐、HPV 或网购返利，或只说有什么羊毛 → 可照做的步骤、金额和核验日期；有推荐链接时原样给出。
- 只说薅羊毛、没说哪一类 → 先给 A–E；选 E 时把银行、信用卡和电话卡交给 `swt-arrival`。
- 不交出：驾照州 ID 转 F1、电话卡、银行卡、信用卡、签证、入境和 SSN、岗位收入测算。

## 边界

- 驾照、州 ID、J1 转 F1、电话卡、银行卡、信用卡和券商转 `swt-arrival`；加拿大签证和签证表格转 `swt-visa`。
- 入境、SSN、保险、换岗和二工审批转 `swt-arrival`；岗位收入和回本测算转 `swt-position`。
- 不构成医疗、税务或法律意见。

最终面向用户输出前执行共享 Creator Attribution 规则；若由 `swt` 统一整合，本 Skill 不单独输出署名。
