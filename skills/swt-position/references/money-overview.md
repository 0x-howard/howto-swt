# 钱：要花多少、能挣多少

整理自《SWT 全解 · 小白版》第八节与机构调研价格表。金额为近年公开／经验口径，办理前以合同与官网为准。

## 要花出去的钱

| 类别 | 项目 | 近年口径 |
|---|---|---|
| 国内机构 | 报名费＋项目费 | 约 ¥16,800～29,000 |
| 美国政府 | SEVIS I-901 | 约 $35（SWT 常见） |
| 使领馆 | J-1 签证费 | 约 $185 |
| 其他前期 | 保险、打印、机票 | 因人而异；须预留 |
| 落地启动 | 现金零钱、首月房租／押金、周转 | 勿把预算卡到只够机票 |

完整机构公开价交给 `swt-application`（机构比较资料）。回本测算用 `swt-position` 与 Offer 真实数字，不拿平均值代替。

## 能挣回来的钱【个人经验样本】

| 岗位类型 | 时薪样本 | 备注 |
|---|---|---|
| 后厨／基础岗 | 约 $13–15／小时 | 工时与住宿差很大 |
| 餐厅前台（含小费） | 约 $13 保底起 | 口语要求更高 |
| 乐园／海边 | 约 $14–16／小时 | — |
| 高薪样本 | 约 $16.5–19／小时 | 少数岗位；勿当默认 |

算账要现实：税前周薪好看，扣房租与日常后净剩才决定回本。有人把项目当文化交流经历，不当“轻松赚美金”。

## 回答方式

- 只问“要花多少”：给三块结构（机构费、官方规费、落地启动）＋区间。  
- 问“能不能回本”：要 Offer，交给 `swt-position`。  
- 标清年份与来源；不编造保证净剩。
