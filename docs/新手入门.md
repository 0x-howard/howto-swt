# 新手入门

HowTo SWT 是给 J-1 Summer Work Travel 学生用的 AI Skills。你不用先搞懂 6 个 Skill 的区别，直接说你遇到的事，小How 会交给对应的 Skill

## 安装

在终端运行：

```bash
npx -y skills add 0x-howard/howto-swt -g --all
```

更多安装方式见[安装说明](INSTALL.md)

## 第一次使用

开一个新对话，输入：

```text
你好小How
```

小How 会给你一个简短的菜单。也可以直接说任务：

- 小How，帮我比较这两个 Offer
- 小How，帮我准备 Sponsor 面试
- 小How，帮我核对签证材料

只说"你好""hi""在吗"不会叫出小How，要带上"小How"或"HowTo SWT"

## 6 个 Skill 分别做什么

| 你要做的事 | Skill |
| --- | --- |
| 不知道现在该做什么 | `swt` |
| 报名、机构、Sponsor、合同付款、申请材料 | `swt-application` |
| 看 Offer、比较岗位、算回本 | `swt-position` |
| 测英语、练口语、模拟面试 | `swt-english` |
| DS-2019、DS-160、SEVIS 费、面签 | `swt-visa` |
| 行前、入境、SSN、换岗、在美生活 | `swt-arrival` |

## 怎样问效果更好

- 说清项目年份、Sponsor、雇主和目前进度。同一个对话里说过的，小How 会记住
- 比较岗位时，给出时薪、每周工时、住宿费、地点和日期。没给的，小How 会用参考值先算，并标上"估"
- 可以直接发 Offer 的 PDF 或截图
- 签证问题请用你手上的真实材料。DS-2019 和 DS-160 对不上时，先找 Sponsor 确认，再改草稿

## 英语练习怎么选

| 你想要 | 这样说 |
| --- | --- |
| 测一下现在的英语水平 | 帮我测一下 Sponsor 面试英语 |
| 按弱项练习，每题给反馈再重答 | 按我的弱项练口语 |
| 完整模拟一场面试，结束后再点评 | 陪我模拟签证面试 |
| 分析一段面试录音 | 帮我看看这段面试录音（附上文件） |
| 重答刚才那题 | 我想重新回答这题 |
| 接着上次的练习 | 继续上次的练习 |

工作和生活里的英语表达，也可以直接问
