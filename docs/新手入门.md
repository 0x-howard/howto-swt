# HowTo SWT 新手入门

HowTo SWT 是面向 J-1 Summer Work Travel（J1 SWT）参与者的 SWT Skill。你可以直接说明当前遇到的事，不必先知道六个入口的区别；HowTo SWT 会根据任务进入对应的专项 Skill。

## 安装

目标安装命令是：

```bash
npx -y skills add 0x-howard/howto-swt -g --all
```

它会从公开仓库中发现 `skills/` 下的六个 `SKILL.md` 并安装到 Skills CLI 支持的 Agent。当前仓库完成 GitHub 改名和发布前，这条命令暂不可用，也尚未进行线上安装验证。安装器支持范围见 [Skills CLI 支持列表](https://github.com/vercel-labs/skills#supported-agents)。

## 第一次使用

安装并让 Agent 重新发现 Skills 后，可以输入：

```text
你好小How
```

也可以直接交代任务：

- 小How，帮我比较这两个 Offer。
- 小How，帮我准备 Sponsor 面试。
- 小How，帮我核对签证材料。

明确称呼“小How”“HowTo SWT”或 `howto-swt` 会调用 HowTo SWT 主入口；已说清任务时会直接处理。单独说“你好”“hello”“hi”或“在吗”不会要求未激活的 Agent 抢占。

## 主要入口

| 你要做的事 | 入口 |
|---|---|
| 判断 SWT 阶段与下一步 | `swt` |
| 报名、机构、Sponsor 或申请材料 | `swt-application` |
| 比较岗位、Offer、地点和收益 | `swt-position` |
| 测英语、按弱项练习或模拟面试 | `swt-english` |
| 核对 J-1 签证材料、准备面签 | `swt-visa` |
| 准备赴美、入境和在美事项 | `swt-arrival` |

不确定入口时，直接说“我现在已经拿到 Offer，下一步要做什么”或“我不知道这个问题属于哪一步”。

## 提供信息的小技巧

- 说清项目年份、阶段、Sponsor 或雇主；已说过的信息会在当前 conversation 复用。
- 比较岗位时，尽量提供工资、工时、住房、地点、通勤和日期。缺少普通规划信息时，系统会标明使用的估值。
- Visa 问题以核实后的真实材料为准。DS-2019、DS-160 或其他事实冲突时，先核实再优化表达。
- 英语练习可以指定 Agency、Sponsor、Host 或 Visa，也可以让系统根据最近一次 Assessment 选择弱项。

## 英语功能怎么选

- `ASSESS`：正式测量当前 SWT 场景英语准备度。
- `PRACTICE`：按测评弱项或你选的场景练习；每题短反馈后先 Retry，再继续。
- `INTERVIEW`：角色扮演面试官，模拟 Sponsor、雇主或 Visa 面试。
- `GENERAL ENGLISH`：工作沟通、日常英语和一般表达纠错。

Practice 的即时表现不会覆盖正式 Assessment Result。需要复测时直接说“重新测一下”。
