# SWT 入门：是什么、不是什么、黑话、角色、误区

整理自 2026-11-27《SWT 全解 · 小白版》与第一课 PPT 顺序。标【官方】= 国务院／移民局／IRS 等；【机构】= 中介或基金会说法；【个人】= 学生经验。冲突以官方为准。不构成法律或移民意见。

## 一句话说清

SWT = Summer Work & Travel，J-1 交流访问签证下的暑期工作旅行：在读大学生用暑假去美国合法打工约 2–4 个月，再回国继续读书。官方定义见 [BridgeUSA SWT](https://j1visa.state.gov/programs/summer-work-travel/)。

硬事实【官方】：最长停留约 4 个月；须在大学开学前回国；可多次参加；入境前通常先有工作（签证豁免国家除外）；看的是在校身份，不是单纯年龄。

## SWT 不是什么

| 项目 | 和 SWT 的区别 |
|---|---|
| ITP（Intern／Trainee） | 专业实习／培训，时长更长，要和专业或职业相关；规则不能套到 SWT |
| Camp Counselor | 夏令营辅导员，不是普通打工 |
| 打工度假签 | 中国大陆学生没有常规打工度假签；别把 SWT 叫成这个 |
| F-1／B1-B2 打工 | F-1 校内工作受限；旅游签打工违法 |

面签回答围绕文化交流，不要反复强调 work。【个人】

## 五个角色

```
学生 →（可选）国内机构 → Sponsor（美国基金会，签 DS-2019）→ Host Employer → 美国政府
```

Sponsor 才是项目关键主体；国内机构是渠道。付款前让机构写出合作 Sponsor 的英文法定名，到 [BridgeUSA 名录](https://j1visa.state.gov/sponsors/) 核对。

## 黑话速查

| 黑话 | 意思 |
|---|---|
| J-1 | 交流访问签证类别 |
| Sponsor／基金会 | 有资质的项目主办方，签发 DS-2019 |
| DS-2019 | 资格证明，项目起止日期在上面 |
| DS-160 | 面签前在线非移民签证申请表 |
| SEVIS／I-901 | 身份系统／备案费；SWT 常见为 35 美元 |
| I-94 | 入境记录与停留期限 |
| SSN | 社会安全号，发工资和报税常用 |
| W-2 | 雇主年收入税务表 |
| Job Offer／PAF | 岗位录用或项目接受确认 |
| 口测 | 国内机构自设英语选拔 |
| 配岗 | 机构分配岗位，不是自由选岗 |
| OPT | F-1 事物，与 SWT 无关 |

## 中介还是 DIY

| | 国内机构 | DIY |
|---|---|---|
| 适合 | 第一次参加、需要有人盯节点 | 检索能力强、英语好、愿自己盯 |
| 要点 | 看清合同、退款、含什么费用 | 仍须有 Sponsor 签 DS-2019，不是绕过 Sponsor |

第一次参加可找靠谱机构推进度；不推荐具体机构名。学校合作机构常更贵，但请假和成绩认定可能更方便。【个人】

## 常见误区

1. SWT 不是打工度假签。  
2. 最便宜不一定最好，要比含什么。  
3. 越晚报名选择通常越少，不是越好。  
4. DS-2019 到手不等于结束，后面还有 SEVIS、面签、激活。  
5. 提前入境最多约 30 天且不能工作。  
6. 结束后只有约 30 天宽限期且不能工作；被提前终止通常没有宽限期。  
7. 第二份工作须先问 Sponsor。  
8. ITP 与 SWT 不是同一套规则。  
9. 风景好不等于体验好；岗位、住宿、通勤、二工更关键。

## 十大风险（防什么）

1. 拒签／退出后不退费 → 签前看清退款节点与凭证。  
2. 托儿／软文带节奏 → 多源交叉验证。  
3. SEVIS 身份 → 记住激活、变更报告、提前入境限制。  
4. 面签号抢不到 → DS-2019 当天约号。  
5. SSN 拖工资 → 抵达后按官方建议时机办理并跟催。  
6. 烂岗（工时不足、住宿贵）→ 用时薪／工时／住宿／交通／强度／二工机会筛。  
7. 学校请假没办 → 提前办，勿旷课。  
8. 拿不到 W-2 → orientation 当天保存雇主系统账号。  
9. 政策变动 → 出发前向 Sponsor 与使领馆核实。  
10. 心态落差 → 按文化交流＋打工，不按“轻松赚美金”预期。

有公开避雷讨论的机构名可指向调研资料，但须标明“有人在说≠事实认定”，以合同与官方回复为准。

## 关键死线【官方摘要】

- 项目开始日后约 30 天内：Sponsor 须激活 SEVIS。  
- 面签前至少约 3 个工作日：交 SEVIS I-901。  
- 提前入境 ≤ 约 30 天，且不能工作。  
- 项目最长约 4 个月。  
- 结束后约 30 天宽限期，只能旅游。  
- 住址／电话／邮箱／工作地点变更：约 10 天内报 Sponsor。  
- 报税：有预扣常见 4 月 15 日前；无预扣常见 6 月 15 日；离境前关注 IRS 税务离境证明要求。

软死线【个人经验】：9–11 月看岗位；12 月前尽量定岗；拿到 DS-2019 当天约面签。
