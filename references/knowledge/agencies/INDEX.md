# 国内机构公开价与口碑数据（application）

供 **`swt-application`** 选机构／比价／看避雷模式时查询。数据来自 2026-11-27《SWT 机构调研 · 交叉验证》蒸馏。

- 机器可读：`agencies-market-2026.json`／`.csv`
- 脚本：`python3 scripts/agency_market.py --name 西米` 或 `--list`
- 人读摘要：[agency-market-2026.md](../../agency-market-2026.md)

**规则**：价格带年份；避雷是「有人在说」；冲突原样列出；不替学生选型付款。
