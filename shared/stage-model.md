# SWT Stage Model

Stage 是用户当前状态，不是 Skill。阶段编号用于内部定位，不是美国官方流程，也不得与 Skill 一一对应。

## 判断原则

1. 用最近一项有证据的完成事件定位，不以模糊自述或文件夹名称定位。
2. 同时存在多条事项时，分别标出主线阻塞项和可并行项。
3. 状态统一为：未收到、已收到待核对、待本人操作、已提交待审核、已通过、需更正、已过期／被替代。
4. “已准备”不等于“已提交”，“已提交”不等于“已通过”。
5. 金额、截止、入口、材料要求和审批以本人当届通知为准。
6. 阶段不明且会改变路径时，按交互协议问一个可观察的阶段选择题。

## 阶段门槛

| 阶段 | 主要任务 | 完成证据 |
|---|---|---|
| 00 报名、合同与付款 | 核对主体、产品年度、金额、渠道、包含项与退款 | 适用协议、付款状态和下一阶段通知明确 |
| 01 初始申请材料 | 准备真实、清晰、命名一致且必要的材料 | 机构或 Sponsor 确认完整，或给出具体修改项 |
| 02 岗位申请与配岗 | 核对岗位、日期、职责、住宿、通勤和申请规则 | 申请对象、Sponsor、选岗方式和提交状态明确 |
| 03 面试工具准备 | 核对账号、姓名、时区、设备、链接和时间 | 设备测试完成，入口和本人时区时间确认 |
| 04 Sponsor 面试 | 准备真实个人情况、项目理解和岗位信息 | Sponsor 书面给出结果或后续要求 |
| 05 雇主面试与 Offer | 核对职责、日期、工资工时、住宿交通和变更条款 | 结果明确；本人核对并决定是否签署 |
| 06 签证准备 | 建立真实信息底稿，解决跨文件冲突 | DS-160 草稿经本人核对，材料和预约前提明确 |
| 07 DS-2019 与 SEVIS Fee | 核对身份、Sponsor、SEVIS、类别、地点、日期和缴费状态 | 错误获 Sponsor 更正或确认；本人保存可用文件与收据 |
| 08 签证申请与面签 | 核对确认号、预约、费用、材料和真实回答 | 护照与签证状态明确，或进入补件／行政审理分支 |
| 09 赴美前准备 | 确认入境／到岗日期、机票、住宿、接驳、保险和联系方式 | 行程与到达安排确认；原件和应急信息随身 |
| 10 抵美后与在美期间 | I-94、SEVIS Check-in、SSN、保险、定期任务与变更 | 持续满足 Sponsor 要求，变更均有适用批准／回执 |
| 11 项目结束与回国 | 最后工资、押金、保险、离境、留存和税务后续 | 按适用日期离境，待办有记录与责任人 |

## 下一动作检查

流程导航至少确认：当前阶段与最近完成证据、当前阻塞、下一动作与责任人、截止与时区、输入材料及版本、提交渠道、完成回执。用户只问具体操作时不展开整张阶段表。

风险与必须暂停的信号统一由 `risk-policy.md` 管理。
