# 官方核验入口

入口复核于 2026-09-21。入口存在不代表已核验某机构、Sponsor、城市、雇主或个人申请；运行时仍需记录实际访问日期和适用年度。

| 要核查什么 | 官方来源 | 范围与限制 |
|---|---|---|
| SWT 基础资格、项目期限、岗位限制与 Sponsor 职责 | https://j1visa.state.gov/programs/summer-work-travel 与 https://j1visa.state.gov/summer-work-travel-resource-page/ | 不能用机构招生条件代替官方资格；当年参与者信与 Sponsor 通知也需核对 |
| Sponsor 是否具有 SWT 类别 | https://j1visa.state.gov/participants/how-to-apply/sponsor-search/ | 过滤 Summer Work Travel 并核对法人主体；总部地址不代表岗位分布 |
| 现行 SWT 规则 | https://www.ecfr.gov/current/title-22/chapter-I/subchapter-G/part-62/subpart-B/section-62.32 | 使用时核对现行版本和生效日期，不靠第三方摘要代替正文 |
| J-1 签证流程与材料总入口 | https://travel.state.gov/content/travel/en/us-visas/study/exchange.html | 预约顺序和材料会因申请地点变化，继续进入申请地使领馆当前说明 |
| DS-160 官方入口 | https://ceac.state.gov/genniv/ | 申请人必须本人核对并电子签名；页面提示会话空闲 20 分钟可能超时，应保存 Application ID 并经常保存 |
| 照片要求 | 从 J-1 签证页进入 Photograph Requirements | 不把历史教程中的像素、文件大小或纸质照片数量当永久规则 |
| 签证面谈地点、费用、护照返还与本地要求 | 申请地美国使领馆当前页面；从 https://www.usembassy.gov/ 进入 | 不使用历史截图中的领馆、收费或预约入口作唯一依据 |
| I-901 SEVIS 费与收据 | https://www.ice.gov/sevis/i901 与其指向的官方支付入口 | 先确认本人是否需付、谁已付及 SEVIS ID；不重复支付或套用他人收据 |
| I-94 入境记录 | https://i94.cbp.dhs.gov/home | 入境后核对本人记录；信息错误走 CBP 当前更正流程 |
| SSN 首次申请与材料 | https://www.ssa.gov/number-card/request-number-first-time 与 https://www.ssa.gov/ssnumber/ss5doc.htm | SSN 申请免费；J-1 材料和可办理时间还需结合 Sponsor 报到要求 |
| 临时工作／教育访问者权利与求助 | https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/rights.html | 适用于 J-1 的权利材料；紧急情况优先使用 911 或页面列出的当前求助渠道 |
| 工资与加班 | https://www.dol.gov/agencies/whd 及所在州劳动部门 | 不默认所有 SWT 岗位适用同一加班条件 |
| 联邦税务 | https://www.irs.gov/ | 税年、身份、工资单和报税问题分开处理；不把预扣税等同最终税额 |
| 实际交通与住宿 | 当地交通运营方、住房合同与出具方 | 城市介绍文章不能证明末班车、个人租金或租约责任 |

保险不设统一官方入口。必须从本人 Sponsor 门户、保险卡或正式保单进入保险公司渠道；营销简介、旧年度教程和其他参与者的计划不能替代本人 certificate。

本 Skill 不声称存在完整当季市场数据库。页面无法访问、需要登录或当前文件缺失时，明确缺口并用本人原件补充，不把搜索摘要当完整规则或合同。
