# 给维护者的数据收集清单

目标：先支撑几组真实用户的比较，不要求一次收齐全部机构或 50 个州。下面的数量是首批开发建议，不是推荐可信度的统计门槛。

## 第一批最需要的资料

| 优先级 | 原始资料 | 需要保留的细节 | 建议第一批 |
|---|---|---|---|
| P0 | 机构当季完整产品包 | 国内签约主体、2027 年招生条件、完整报价及包含项、合同与退款条款、选岗规则、关联 Sponsor 证据、有效日期 | 学员最常问的 3—5 家；不同价位和选岗路径 |
| P0 | 真实脱敏 offer 及配套住房 | 完整岗位职责、工资工时、日期、排班、扣款、住房租期押金厨房、通勤；不能只给宣传封面 | 6—10 份，尽量构成同一用户可选的两两组合 |
| P0 | 用户原话与选择过程 | 阶段、预算、底线、候选、为什么纠结、已有信息、最终选择及理由 | 5—10 例，含预算紧、英语目标、同行、拒绝夜班等差异 |
| P1 | Sponsor 当季手册／书面回复 | 对应产品和参与者，换岗二工、报到、支持渠道、住房问题处理 | 先覆盖上述机构和 offer 关联的 Sponsor |
| P1 | 往届岗位实绩 | 年份、具体雇主地点、每周工时与工资、实际房租交通、问题如何处理 | 每个重点组合尽量收不同人的记录；不足时按个案呈现 |
| P1 | 具体地点生活证据 | 房源与账单、超市和交通路线、末班车、支持组织当前活动 | 随上述岗位收集，优先具体地址片区 |
| P1 | 二工完整案例 | 招聘时间、本人条件、安排、通勤、Sponsor 确认、实际开工与工时 | 成功、未找到、未确认、放弃均收；不只收成功故事 |
| P2 | 当季岗位库存及变动 | 名额核验时间、锁岗截止、关闭或改价记录 | 只有来源允许且能持续更新时维护 |
| P0 | 脱敏流程事件 | 阶段、通知时间、截止时区、责任方、提交渠道、回执、阻塞与下一动作 | 每个重点阶段至少 1—2 个成功与异常样本 |
| P1 | 同一学生的跨文件字段 | 护照／学籍／Offer／DS-160／DS-2019／预约之间的字段一致性结果，不保存号码原值 | 用于测试冲突识别和停止条件 |

机构的一句“合作很多 Sponsor”不够；请给出这一个产品当季对应哪家、谁有选择权以及证明。二工的一句“很好找”不够；请说明谁、何时、在哪、何种条件、是否确认及实际结果。

## 用户可以直接发送的资料包

每家机构一个文件夹：`报价／合同／招生条件／选岗规则／Sponsor证明`；每个岗位一个文件夹：`offer／住房／通勤／实绩`。另附项目年份、取得日期、出具方、允许使用范围。命名随用户习惯即可，助手负责映射到数据字典。

优先完整 PDF、网页链接和完整截图；整理表可辅助，但不要只交摘要。私人联系方式、证件、账户和签名先遮挡。用户不用收集政策全文，助手可查官方规则；无法联网时明确缺口。
